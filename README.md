# **BASH/EXPRESS**

## Proyecto realizado para poner a prueba mis conocimientos sobre Bash y sobre Express.

### Requisitos:

                *un IDE a tu gusto,
                *Node 20.11+,
                *Bash (o WSL en windows)

### Para inicializarlo:

```bash

    - git clone
    - cd <>
    - npm install
    - npm start
```

## Scripts

| Comando       | Descripción                    |
| ------------- | ------------------------------ |
| `npm start`   | Arranca el servidor            |
| `npm run dev` | Arranca con recarga automática |
